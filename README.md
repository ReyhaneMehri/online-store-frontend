## ✨ About The Project

Online Store is a multi-page e-commerce website that fetches product data from the Fake Store API.

Users can browse products, search and filter items, view detailed product information, add products to their cart, manage quantities, and see the final order total.

The main goal of this project was to go beyond a simple UI and implement the core logic of a real front-end e-commerce application.

## 🛒 Shopping Cart Architecture

One of the main parts of this project is the shopping cart logic implemented with JavaScript.

Cart data is stored in localStorage, allowing the cart to persist even after refreshing the page.

Cart Flow:

Add Product → Cart Array → localStorage → Render Cart → Update Quantity → Calculate Total
