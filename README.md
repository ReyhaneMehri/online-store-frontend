# 🛍️ Online Store | Front-End E-commerce Project

A responsive multi-page e-commerce website built with HTML, CSS, JavaScript, and Bootstrap 5.

This project focuses on implementing real-world front-end features, including API integration, dynamic product rendering, search and filtering, shopping cart management, and responsive UI design.

## ✨ Features

### Product Management
- Fetch and display products from Fake Store API
- Dynamic product rendering
- Product details page
- Product ratings and information

### Search & Filtering
- Search products by title
- Filter products by category
- Sort products by price

### Shopping Cart
- Add and remove products
- Increase and decrease product quantities
- Calculate subtotal and total price
- Apply discounts
- Save cart data using LocalStorage
- Persist cart data after page refresh

### Responsive Design
- Mobile-first responsive layouts
- Tablet and desktop support
- Mobile bottom navigation
- Responsive product details
- Mobile order summary
